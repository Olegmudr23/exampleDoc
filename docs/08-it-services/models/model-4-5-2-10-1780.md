# Приложение "ОРД по ИБ"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.5.2.10**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Приложение «ОРД по ИБ» является справочником, который содержит перечень документов по информационной безопасности организации. Справочник служит основой для унификации документации по ИБ, упрощает процесс подготовки и согласования документов, а также обеспечивает соответствие внутренним стандартам и требованиям законодательства в области информационной безопасности.

Тип приложения:

Стандартное

Название элемента:

{$Название организации}
