# Приложение "Комплект документов по ИБ"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.5.2.1**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Приложение "Комплект документов по ИБ" является справочником, который хранит информацию о документах, связанных с обеспечением информационной безопасности в организации. Каждая запись отражает наличие и состояние документации по конкретной IT-услуге, организации или объекту контроля, включая акты установки и настройки СЗИ, акты проведения проверок и технические паспорта. Приложение позволяет отслеживать сроки оформления документов и автоматически фиксировать превышение допустимого периода оформления.

Тип приложения:

Стандартное

Ограничить доступ к данным*: На уровне элементов приложения
