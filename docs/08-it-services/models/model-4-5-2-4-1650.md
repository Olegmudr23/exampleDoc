# Приложение "Акты проведения ПИ"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.5.2.4**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Приложение "Акты проведения приемочных испытаний" является справочником, который хранит информацию о документах, фиксирующих результаты проверки готовности информационных систем и средств защиты информации к вводу в эксплуатацию. Каждая запись отражает сведения об объекте испытаний, перечне проведённых проверок, дате и итогах испытаний, а также об ответственном исполнителе. Приложение позволяет отслеживать наличие и корректность оформления актов.

Тип приложения:

Документ
