# Приложение "АРМ организаций"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.5.2.6**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Приложение «АРМ организаций» является справочником, который содержит сведения об автоматизированных рабочих местах (АРМ), используемых в организации. Каждая запись отражает состав и характеристики рабочих мест сотрудников, включая установленные программные и аппаратные средства, средства защиты информации. Приложение используется для учета и контроля соответствия АРМ требованиям информационной безопасности, отслеживания изменений конфигурации, проведения проверок защищенности и планирования мероприятий по обеспечению ИБ.

Тип приложения:

Стандартное

Название элемента:

$Название организации} {$Наименование РМ}
