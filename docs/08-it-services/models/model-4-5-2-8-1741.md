# Приложение "Средства защиты информации"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.5.2.8**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Приложение «Средства защиты информации» является справочником, который содержит перечень возможных программных и аппаратных средств защиты информации, применяемых в организациях. Каждая запись включает сведения о типе СЗИ, его названии и сертификате. Справочник используется как основа для указания средств защиты, обеспечивая единообразие при ведении связанных реестров и документировании процессов информационной безопасности.
