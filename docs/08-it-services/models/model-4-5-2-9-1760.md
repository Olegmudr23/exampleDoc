# Приложение "Стандарты документов ИБ"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.5.2.9**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Приложение «Стандарты документов ИБ» является справочником, который содержит перечень типовых документов по информационной безопасности, используемых в организациях, а также пример их оформления в виде шаблона. Каждая запись описывает вид документа и формат оформления. Справочник служит основой для унификации документации по ИБ, упрощает процесс подготовки и согласования документов, а также обеспечивает соответствие внутренним стандартам и требованиям законодательства в области информационной безопасности.
