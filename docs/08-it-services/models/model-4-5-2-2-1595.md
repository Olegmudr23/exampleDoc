# Приложение "Техпаспорты"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.5.2.2**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Приложение "Техпаспорты" является справочником, который хранит информацию об АРМ и СЗИ в организации. Каждая запись отражает наличие, состояние и основные характеристики техники, включая сведения о конфигурации, составе оборудования, используемом программном обеспечении и настройках систем защиты информации. Приложение позволяет отслеживать актуальность технических паспортов, даты их обновления.

Тип приложения:

Документ

Название элемента:

{$Сокращенное наименование ИС} {$Количество записей приложения по данной ИС}
