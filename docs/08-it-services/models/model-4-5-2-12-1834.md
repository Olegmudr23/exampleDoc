# Приложение "Операционные системы"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.5.2.12**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Приложение «Операционные системы» является справочником, который содержит сведения об операционных системах, используемых на автоматизированных рабочих местах, серверах и иных вычислительных устройствах организаций. Приложение используется для учета используемых ОС, контроля актуальности и соответствия требованиям информационной безопасности.
