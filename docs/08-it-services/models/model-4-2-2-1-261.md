# Приложение "Оферты для CRM"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.2.2.1**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Оферты для CRM (offers) - официальное, детализированное предложение заключить договор на подключение к CRM. Для реализации используется приложение с типом "Файл".

Статусная модель

Таблица статусов объекта «Оферты для CRM» (Таблица 3).

| № | Ключ | Значение | Примечания |
| --- | --- | --- | --- |
| 1 | new | Новая | Новая оферта, генерируется при запуске БП "Создание Оферты для CRM". |
| 2 | signing | Подписание | Оферта отправлена на подписание. |
| 3 | signed | Подписана | Оферта подписана. |
| 4 | valid | Действует | Оферту согласован сотрудник Оператора. |
| 5 | withdrawn | Отозвана | Оферта отозвана получателем ИТ-услуги/Поставщиком ИТ-услуги |
| 6 | adjustment | Корректировка | Сотрудник Оператора выявил ошибки и вернул оферту на доработку. |
