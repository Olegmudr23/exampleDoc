# Приложение "Информационные системы"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.5.2.11**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Приложение «Информационные системы» является справочником, который содержит сведения о программных комплексах и сервисах, используемых в организации. Каждая запись отражает состав, назначение и основные характеристики информационной системы. Приложение используется для учета и классификации информационных систем, обеспечения прозрачности их взаимодействий, контроля соответствия требованиям информационной безопасности.

Тип приложения:

Стандартное

Название элемента:

{$Сокращенное наименование ИС}
