# Приложение "Формы ознакомления с правилами работы с ДСТ"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.4.2.5**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Приложение "Формы ознакомления с правилами работы с ДСТ" является справочником, который хранит информацию о документах, подтверждающих ознакомление с правилами работы с ДСТ
