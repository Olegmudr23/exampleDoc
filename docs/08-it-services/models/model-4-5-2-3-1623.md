# Приложение "Акты установки и настройки СЗИ"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.5.2.3**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Приложение "Акты установки и настройки СЗИ" является справочником, который хранит информацию о документах, фиксирующих факт установки средств защиты информации. Каждая запись отражает сведения об объекте установки, типе применяемого СЗИ, дате проведения работ, а также об ответственном исполнителе. Приложение позволяет отслеживать корректность и полноту оформления актов.

Тип приложения:

Документ

Название элемента:

{$Сокращенное наименование ИС} {$Количество записей приложения по данной ИС}
