# Страница "Журнал поэкземплярного учета СКЗИ"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.4.2.6**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Журнал поэкземплярного учета СКЗИ - отчет, предназначенный для учета, контроля и отслеживания движения экземпляров средств криптографической защиты информации (СКЗИ), сопроводительной документации и ключевых документов на всех этапах их жизненного цикла (получение, хранение, использование, передача, уничтожение).

Отчет строиться на основе данных приложения "ДСТ"
