# Приложение "Акты оценки требований"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.5.2.5**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

Приложение "Акты оценки требований на эксплуатацию ГИС" является справочником, который хранит информацию о документах, подтверждающих выполнение установленных требований к эксплуатации государственных информационных систем. Каждая запись отражает сведения об объекте оценки, перечне проверенных требований, дате проведения оценки и результатах проверки. Приложение позволяет отслеживать наличие и актуальность актов.

Тип приложения:

Документ

Название элемента:

{$Сокращенное наименование ИС} {$Количество записей приложения по данной ИС}
