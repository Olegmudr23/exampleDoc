# Требования к порталу самообслуживания

[Каталог ТЗ](README.md) · [Все примеры](../../README.md)

Исходный раздел: **4.6**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

В решении Service Desk 2.0 должен быть доступен внешний портал, с помощью которого пользователи могут создавать заявки, просматривать списки доступных услуг, формировать оферты, подключаться к новым услугам, а также читать новости и статьи. В рамках текущего проекта необходимо доработать портал самообслуживания.

## 4.6.1 Страница "Сводный каталог IT-услуг"

*Рисунок 116 - Страница "Сводный каталог IT-услуг" (Фильтр "По направлениям"). — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

*Рисунок 117 - Страница "Сводный каталог IT-услуг" (Фильтр "По поставщикам"). — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Необходимо на портал самообслуживания добавить страницу "Сводный каталог IT-услуг", где будут отображены:

Фильтр "По направлениям/По поставщикам".

В зависимости от фильтра отображать перечень услуг 1 уровня.

При клике на услугу открывается карточка (Карточка услуги). Предусмотреть закрытие карточки услуги.

Страница должна быть доступна выделенным пользователям из БП "Создание оферты для Получателя IT-услуг". Записаны в поле "Ответственные за взаимодействие" в Организации.

## 4.6.2 Страница "Реестр подключенных IT-услуг"

*Рисунок 118 - Страница "Реестр подключенных IT-услуг". — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Необходимо на портал самообслуживания добавить страницу "Реестр подключенных IT-услуг", где будут отображены:

Наименование IT-услуги - название услуги.

Тип IT-услуги - из услуги значение в поле "Тип услуги".

Поставщик IT-услуги - из услуги значение в поле "Поставщик".

Владелец - из услуги значение в поле "Владелец".

Инициатор подключения - автор связанного Юридического документа или Заявки на подключение.

Юридический документ - связанный юридический документ для организации, которая была подключена и имеет статус "Действует". Если не найдено, то "Не требует".

Статус юр. документа - статус связанного документа.

Заявка на подключение - связанная заявка на подключение.

Статус заявки на подключение - статус связанной заявки на подключение.

Подписант - подписант юр. документа.

Пользователи - объект доступности из юр. документа.

На странице должны отображаться все услуги, по которым есть элементы приложения "Заявки на подключение" и "Юридические документы" для организации текущего пользователя.

## 4.6.3 Страница "Реестр заключенных соглашений/оферт"

*Рисунок 119 - Страница "Реестр заключенных соглашений/оферт". — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Необходимо на портал самообслуживания добавить страницу "Реестр заключенных соглашений/оферт", где будут отображены:

Документ - ссылка на форму просмотра юр. документа.

Услуга - Услуга из юридического документа.

Тип - Тип юридического документа.

Статус юр. документа - статус связанного документа.

Подписант - подписант юр. документа.

Отображать все юридические документы для организации текущего пользователя.

## 4.6.4 Страница "Реестр заявок на подключение"

*Рисунок 120 - Страница "Реестр заявок на подключение". — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Необходимо на портал самообслуживания добавить страницу "Реестр заявок на подключение", где будут отображены:

Заявка на подключение - Наименование заявки на подключение.

Услуга - Услуга из заявки.

Тип заявки.

Статус - статус заявки на подключение.

Отображать все заявки на подключение для организации текущего пользователя.

## 4.6.5 Страница "Задачи"

Необходимо на портал самообслуживания добавить страницу "Задачи", где будет отображен реестр задач для текущего пользователя.

## 4.6.6 Страница "Данные об организации"

*Рисунок 121 - Макет Страницы "Данные об организации". — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Отображать "Ответственные за IT" из организации текущего пользователя.

Отображать "АИБ" из организации текущего пользователя.

Отображать "Ответственные за взаимодействие" из организации текущего пользователя.

Вложения (приказы о назначении) из организации текущего пользователя.

Кнопка "Изменить" - открывает форму создания заявки с предзаполненными полями:

Услуга: CRM.Service Desk;

Тип заявки: ЗНО;

СО: Запрос на установку/изменение ответственных;

Тема: "Прошу изменить ответственных";

Текст: 
"Прошу установить ответственными за ИТ:
Сотрудник 1;
Сотрудник 2;
Сотрудник 3.

Прошу установить АИБ:
Сотрудник 1;
Сотрудник 2."

*Рисунок 122 - Карточка услуги — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

## 4.6.8 Страница "Реестр оферт на подключение к CRM"

*Рисунок 123 -Реестр оферт на подключение к CRM — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Необходимо на портал самообслуживания добавить страницу "Реестр оферт на подключение к CRM", где будут отображены:

Оферта для CRM - Наименование оферты (по клику открытие формы просмотра).

Статус - Статус оферты.

Тип оферты - Тип Оферты для CRM

Пригласивший внутренний сотрудник

Отображать страницу, если по текущей организации текущего пользователя есть записи приложения "Оферты". Отображать все записи, у которых организация совпадает с организацией внешнего пользователя.
