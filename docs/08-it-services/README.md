# Техническое задание на подключение ИТ услуг и управление документами

Расширенная обезличенная подборка из технического задания: полные текстовые описания **30 бизнес-процессов**, приложения с атрибутами и правами доступа, требования ко всем страницам портала.

[Все примеры](../../README.md) · [Компактная выборка DOCX](excerpts.docx) · [Портал самообслуживания](portal.md)

## Как читать

Каждый процесс вынесен в отдельную страницу. В ней сохранены все текстовые шаги, условия переходов, входные параметры, зоны ответственности и таблицы исходного раздела. Широкие атрибутивные таблицы представлены раскрывающимися записями: нажмите на название атрибута, чтобы увидеть все параметры.

Число шагов ниже — количество явно описанных шагов исходного процесса. Номера разделов и ссылки на соседние процессы сохранены. Проектные неточности и неоднозначности исходного ТЗ не исправлялись предположениями. Макеты, рисунки и внешние файлы шаблонов в эту текстовую подборку не включены; ссылки на рисунки отмечены в соответствующих местах.
