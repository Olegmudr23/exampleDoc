Бизнес-процесс предназначен для оформления акта оценки выполнения требований на эксплуатацию ГИС с целью подтверждения соответствия системы установленным требованиям.Бизнес-процесс предназначен для оформления акта оценки выполнения требований на эксплуатацию ГИС с целью подтверждения соответствия системы установленным требованиям.

Процесс применяется в рамках приложения "Комплект документов по ИБ".

## Зоны ответственности

Описание зон ответственности БП  "Оформление акта оценки выполнения требований на эксплуатацию ГИС"

| Зона ответственности | Тип | Описание |
| --- | --- | --- |
| АИБ поставщика | Динамическая | Определяется по записи ИС |
| АИБ подписант | Динамическая | Определяется АИБом поставщика в шаге 2 |
| Руководитель поставщика | Динамическая | Определяется АИБом поставщика в шаге 2 |


## Запуск процесса

Процесс запускается автоматически в рамках БП "Оформление документов по ИБ"

Определяется по записи ИС

<a id="step-1"></a>
## Шаг 1 Сценарий "Подготовка данных"

| 2 | Руководитель поставщика | Пользователь | Да | Да | На форме отображать следующее название поля: "Утверждающий (руководитель организации)"<br>Текст подсказки: "Данный пользовать будет указан в качестве подписанта акта" |
