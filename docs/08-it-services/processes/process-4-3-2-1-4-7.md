*Рисунок 25 — Схема бизнес процесса "Отключение услуги". — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Бизнес-процесс предназначен для расторжение соглашения или оферты. Процесс запускается с карточки услуги на форме просмотра или с формы просмотра юридического документа ("Статус" = "Действует")/Заявки на подключение ("Статус" = "Исполнено").

## Зоны ответственности

Описание зон ответственности БП "Отключение услуги".

| Зона ответственности | Тип | Описание |
| --- | --- | --- |
| Инициатор | Динамическая | Пользователь, имеющий доступ на просмотр элемента приложения. |
| Сотрудники организации | Динамическая | Пользователи, которые относятся к организации. |


## Входные параметры

| Входной параметр | Описание |
| --- | --- |
| Юридический документ или Заявка на подключение | Действующий документ или заявка. |
| Услуга | Услуга, которую планируется отключить. |


## Форма запуска

| Параметр | Описание |
| --- | --- |
| "Вы уверены, что хотите отключить услугу?" | Текст. Недоступно для редактирования. |
| Переходы | Да (Переход на шаг 1);<br>Нет (Завершение процесса). |


## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Присваивание "Записать необходимость оформления"

Система автоматически записывает значение из [Юридический документ или Заявка на подключение. Услуга. Необходимо юридическое оформление?] в контекстную переменную процесса. Далее переход на шаг 2.

<a id="step-2"></a>
## Шаг 2 Шлюз "Необходимо юридическое оформление?"

| Переход | Описание |
| --- | --- |
| Да | [Необходимо юридическое оформление?] = "Да".<br>Переход на шаг 3. |
| Нет | По умолчанию.<br>Переход на шаг 4. |


<a id="step-3"></a>
## Шаг 3 Запуск процесса "Формирование юридического документа на расторжение"

Система автоматически запускает БП "Формирование юридического документа на расторжение". Завершение процесса.

<a id="step-4"></a>
## Шаг 4 Сценарий "Удалить подписку"

Система автоматически осуществляет поиск в справочнике "Доступность услуг" связанные структурные единицы, пользователей IT-услуг. В найденных записях удаляет текущую услугу. Далее переход на шаг 5.

<a id="step-5"></a>
## Шаг 5 Сценарий "Получить сотрудников организации"

Система автоматически осуществляет поиск пользователей из организации, указанной в заявке на подключение. Находим всех пользователей и записываем в контекстную переменную процесса.  Далее переход на шаг 6.

<a id="step-6"></a>
## Шаг 6 Смена статус "Заявка на подключение → Отказ"

Система автоматически изменяет статус заявки на подключение на значение "Отказ". Далее переход на шаг 7.

<a id="step-7"></a>
## Шаг 7 Email уведомление "Услуга отключена"

Система автоматически отправляет сотрудникам организации email сообщение. Далее завершение процесса.

| Параметр | Описание |
| --- | --- |
| Название | Услуга не доступна |
| Тема | Услуга: $(Услуга. Название) отключена |
| Текст сообщения | Услуга: $(Услуга. Название) больше недоступна на портале самообслуживания. |
| Обработка ошибок | Завершение процесса. |
