# БП "Создание оферты для CRM"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.2.2.1.4.1**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

*Рисунок 4 — Схема бизнес процесса "Создание оферты для CRM" — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Бизнес-процесс предназначен для формирования ссылки на оферту для дальнейшего подключения к системе CRM. Процесс применяется в рамках приложения " Оферты для CRM". Запуск процесса происходит по кнопке "Создать оферту".

## Зоны ответственности

Описание зон ответственности БП  "Создать оферту"

| Зона ответственности | Тип | Описание |
| --- | --- | --- |
| Инициатор | Динамическая | Ответственные за оферты CRM. |


## Запуск процесса

Запуск процесса происходит по кнопке "Сформировать оферту".

Инициатор — Пользователь с правами доступа на работу с офертами.

| Название | Тип поля | Описание |
| --- | --- | --- |
| Кому отправить ссылку на подключение?* | Элемент приложения "Пользователи IT-услуг". | Для выбора доступно одно из значений. |
| "Получатель IT-услуги/ Внутренний поставщик IT-услуги" * | Категория | Для выбора доступно одно из значений. |
| Кнопка | Описание | Описание |
| Готово | Запуск БП "Создание  Оферты для CRM". | Запуск БП "Создание  Оферты для CRM". |
| Отмена | Отмена запуска процесса. | Отмена запуска процесса. |


## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Присваивание "Записать выбранные параметры"

Система автоматически записывает выбранные параметры в контекстные переменные процесса. Переход на шаг 2.

<a id="step-2"></a>
## Шаг 2 Шлюз "Получатель IT-услуг?"

| Переход | Описание |
| --- | --- |
| Да | "Получатель IT-услуги/Внутренний Поставщик IT-услуги" = "Получатель IT-услуг".<br>Переход на шаг 3. |
| Нет | По умолчанию.<br>Переход на шаг 4. |


<a id="step-3"></a>
## Шаг 3 Запуск БП "Формирование  Оферты для CRM для получателя IT-услуг"

Система автоматически запускает БП "Формирование Оферты для CRM для получателя IT-услуг", передает значение "Кому отправить ссылку на подключение?" . Далее завершение процесса.

<a id="step-4"></a>
## Шаг 4 Запуск БП "Формирование  Оферты для CRM для Внутреннего поставщика IT-услуг"

Система автоматически запускает БП "Формирование Оферты для CRM для Внутреннего поставщика IT-услуг", передает значение "Кому отправить ссылку на подключение?". Далее завершение процесса.
