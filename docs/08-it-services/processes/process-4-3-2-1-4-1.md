Бизнес-процесс предназначен для запуска процесса по подключению выбранной IT-услуги. Процесс запускается на портале подключения к IT-услугам из карточки услуги.

## Зоны ответственности

Описание зон ответственности БП "Подключение IT-услуги"

| Зона ответственности | Тип | Описание |
| --- | --- | --- |
| Инициатор | Динамическая | Пользователь портала по подключению IT-услуг. |


## Входные параметры

Инициатор — Пользователь с правами доступа на работу с офертами.

| Входной параметр | Описание |
| --- | --- |
| Услуга | Услуга, которую выбрал инициатор процесса на портале по подключению IT-услуг. |


## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Сценарий "Проверить необходимость оформления документов"

Система автоматически записывает значение в услуге "Необходимо юридическое оформление?" в контекстную переменную процесса. Переход на шаг 2.

<a id="step-2"></a>
## Шаг 2 Шлюз "Необходимо оформление документов?"

| Переход | Описание |
| --- | --- |
| Нет | По умолчанию.<br>Переход на шаг 3. |
| Да | [Необходимо юридическое оформление?] = "Да"<br>Переход на шаг 4. |


<a id="step-3"></a>
## Шаг 3 Запуск процесса "БП "Подключение IT-услуги без юр. оформления"

Система автоматически запускает БП "Подключение IT-услуги без юр. оформления". Завершение процесса.

<a id="step-4"></a>
## Шаг 4 Запуск процесса БП "Подключение IT-услуги требующей юридического оформления"

Система автоматически запускает БП "Подключение IT-услуги требующей юридического оформления". Завершение процесса.
