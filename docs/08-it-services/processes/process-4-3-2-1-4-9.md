# Бизнес-процесс "Расторжение в одностороннем порядке"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.3.2.1.4.9**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

*Рисунок 28 — Схема бизнес процесса "Расторжение в одностороннем порядке". — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Бизнес-процесс предназначен для отправки на подпись документа для Юридических документов, у которых "Категория документа" = "Расторжение" и "Статус" = "Новое" или "Отказ. Кнопка "Расторгнуть в одностороннем порядке" доступна только поставщикам (внутренние пользователи).

## Зоны ответственности

Описание зон ответственности БП "Расторжение в одностороннем порядке".

| Зона ответственности | Тип | Описание |
| --- | --- | --- |
| Инициатор | Динамическая | Внутренний пользователь, который работает с юр. документами. |
| Подписант | Динамическая | Подписант документа. |
| Сотрудники | Динамическая | Сотрудники отключаемой организации. |


## Входные параметры

| Входной параметр | Описание |
| --- | --- |
| Юридический документ | Юридический документ, который отправлен на подписание |
| Инициатор | Внутренний пользователь, который работает с юр. документами. |


## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Задача "Выбрать подписанта"

Инициатор получает задачу:

| Параметр | Описание |
| --- | --- |
| Название | Выбрать подписанта для документа о расторжении |
| Оповещение | Оповещать исполнителя о постановке задачи |
| Переназначение | Да |
| Выполнять от имени | Система. |
| Правила исполнения | Кто первый? |
| Форма задачи | Описание |
| Подписант | Доступен для выбора внешний пользователь. |
| Переходы | Готово (Переход на шаг 2) (Записать внешнего пользователя в Юридический документ).<br>Отменить (Завершение процесса). |


<a id="step-2"></a>
## Шаг 2 Смена статуса "Юридический документ → На подписании"

Система автоматически изменяет статус документа на значение "На подписании". Далее переход на шаг 3.

<a id="step-3"></a>
## Шаг 3 Задача "Подписать юридический документ"

Подписант (внешний пользователь) из юридического документа получает задачу , чтобы подписать УКЭП (КриптоПРО) оферту.

| Параметр | Описание |
| --- | --- |
| Переназначение | Нет |
| Приложение | Юридический документ |
| Выход при успешном подписании | Шаг 6. |
| Выход при неуспешном подписании | Шаг 4. |
| Провайдер по умолчанию | КриптоПро |


На подписание дается 14 дней, в случае просрочки переход на шаг 10. Предусмотреть комментирование при отказе в подписании.

<a id="step-4"></a>
## Шаг 4 Смена статуса "Юридический документ → Отказ"

Система автоматически изменяет статус текущего документа на значение "Отказ". Далее переход на шаг 5.

<a id="step-5"></a>
## Шаг 5 Уведомление "Документ не подписан"

Система автоматически направляет инициатору сообщение. Далее завершение процесса.

| Параметр | Описание |
| --- | --- |
| Название | Документ не подписан |
| Тема | Документ о расторжении не подписан. |
| Текст сообщения | Документ о расторжении не подписан.<br>Причина: $(Из шага 9 или документ не подписан вовремя). |
| Автор | Система |
| Ассоциированный объект | Текущий процесс. |


<a id="step-6"></a>
## Шаг 6 Смена статуса "Юридический документ → Подписано"

Система автоматически изменяет статус текущего документа на значение "Подписано. Далее переход на шаг 7.

<a id="step-7"></a>
## Шаг 7 Сценарий "Автоматическое удаление подписок"

Система автоматически автоматически удаляет все подписки организации/структурной единицы/пользователя IT-услуги на IT-услугу. Далее переход на шаг 8.

<a id="step-8"></a>
## Шаг 8 Смена статуса "Юридический документ → Действует"

Система автоматически изменяет статус текущего документа на значение "Действует". Далее переход на шаг 9.

<a id="step-9"></a>
## Шаг 9 Сценарий "Получить список сотрудников, которым уже недоступна услуга"

Система автоматически из доступности услуг получает список тех пользователей, которым была доступна услуга и записывает в контекстную переменную процесса. Далее переход на шаг 10.

<a id="step-10"></a>
## Шаг 10 Оповещение на email "Услуга отключена"

Cистема автоматически отправляет email полученным пользователям:

| Тема сообщения | Услуга отключена |
| --- | --- |
| Текст сообщения | Добрый день!<br><br>Теперь вы не можете формировать заявки по услуге $(Юридический документ. Услуга. Название) на портале самообслуживания. |
| Обработка ошибок | Переход на шаг 11. |


<a id="step-11"></a>
## Шаг 11 Смена статуса "Юридический документ → Расторгнуто"

Система автоматически изменяет статус документа из которого создан текущий документ на значение "Расторгнуто". Завершение процесса.
