# Бизнес-процесс "Подписание юридического документа"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.3.2.1.4.5**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

*Рисунок 23 — Схема бизнес процесса "Подписание юридического документа". — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Бизнес-процесс предназначен для оферты или соглашения для юридического документа. Процесс запускается по кнопке "Отправить на подписание" на форме просмотра юридического документа, у которого "Статус" = "Новое" или "Отказано".

## Зоны ответственности

Описание зон ответственности БП "Подключение IT-услуги требующей юридического оформления".

| Зона ответственности | Тип | Описание |
| --- | --- | --- |
| Инициатор | Динамическая | Пользователь портала по подключению IT-услуг. |
| Подписант | Динамическая | Подписант документа. |
| Дополнительный подписант | Динамическая | Подписант документа. |
| Поставщик IT-услуг | Динамическая | Пользователи, которые относятся к поставщику IT-услуг. |
| Подключенные сотрудники | Динамическая | Сотрудники подключаемой организации. |


## Входные параметры

| Входной параметр | Описание |
| --- | --- |
| Юридический документ | Юридический документ, который отправлен на подписание |
| Инициатор | Внешний пользователь, который работает на портале по подключению IT-услуг. |


## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Присваивание "Записать категорию документа"

Система автоматически записывает значение из [Юридический документ. Категория документа] в контекстную переменную процесса. Далее переход на шаг 2.

<a id="step-2"></a>
## Шаг 2 Смена статуса "Юридический документ → На рассмотрении"

Система автоматически изменяет статус документа на значение "На рассмотрении". Далее переход на шаг 3.

<a id="step-3"></a>
## Шаг 3 Сценарий "Получить группу поставщиков"

Система автоматически находит группу поставщиков, которая относится к услуге, указанной в документе и записывает в контекстную переменную процесса. Далее переход на шаг 4.

<a id="step-4"></a>
## Шаг 4 Шлюз "Соглашение?"

| Переход | Описание |
| --- | --- |
| Соглашение | [Категория документа] = "Соглашение".<br>Переход на шаг 13. |
| Оферта | По умолчанию.<br>Переход на шаг 5. |


<a id="step-5"></a>
## Шаг 5 Задача "Рассмотреть оферту"

Пользователи полученные на шаге 4 получают задачу на рассмотрение оферты:

| Параметр | Описание |
| --- | --- |
| Название | Рассмотреть оферту на подключение IT-услуги |
| Оповещение | Оповещать исполнителя о постановке задачи |
| Переназначение | Да |
| Выполнять от имени | Система. |
| Правила исполнения | Кто первый? |
| Форма задачи | Описание |
| Юридический документ | Форма просмотра элемента приложения "Юридический документ" |
| Переходы | Готово (Переход на шаг 8).<br>Отменить (Переход на шаг 6, предусмотреть комментарий обязательный). |


<a id="step-6"></a>
## Шаг 6 Смена статуса "Юридический документ → Отказ"

Система автоматически изменяет статус документа на значение "Отказ". Далее переход на шаг 7.

<a id="step-7"></a>
## Шаг 7 Уведомление "В подключении отказано"

| Название | В подключении отказано. |
| Тема | Подключение IT-услуги |
| Текст сообщения | В подключении IT-услуги $(Услуга. Название) отказано, в связи с: $(Комментарий, указанный на шаге 5). |
| Автор | Система. |
| Ассоциированный объект | Текущий процесс. |

## Шаг 8 Смена статуса "Юридический документ → На подписании"

Система автоматически изменяет статус документа на значение "На подписании". Далее переход на шаг 9.

<a id="step-9"></a>
## Шаг 9 Задача "Подписать оферту"

Подписант (внешний пользователь) из юридического документа получает задачу , чтобы подписать УКЭП (КриптоПРО) оферту.

| Переназначение | Нет |
| --- | --- |
| Приложение | Юридический документ |
| Выход при успешном подписании | Шаг 12. |
| Выход при неуспешном подписании | Шаг 10. |
| Провайдер по умолчанию | КриптоПро |


На подписание дается 14 дней, в случае просрочки переход на шаг 10. Предусмотреть комментирование при отказе в подписании.

## Шаг 10 Смена статуса "Юридический документ → Отказ"

## Шаг 24 Сценарий "Получить список сотрудников, которым доступна услуга"

Система автоматически из доступности услуг получает список тех пользователей, которым доступна новая услуга и записывает в контекстную переменную процесса. Далее переход на шаг 25.

<a id="step-25"></a>
## Шаг 25 Оповещение на email "Успешное подключение"

Cистема автоматически отправляет email полученным пользователям:

| Тема сообщения | $(Юридический документ. тип) на подключение IT-услуг согласована |
| --- | --- |
| Текст сообщения | Добрый день!<br><br>Теперь вы можете формировать заявки по услуге $(Юридический документ. Услуга. Название) на портале самообслуживания. |

Система автоматически запускает БП "Оформление документации по ИБ", Если указано соответствующее свойство в услуге . Завершение процесса.

Иначе, Завершение процесса.
