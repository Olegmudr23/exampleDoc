# БП "Оформление акта проведения приемочных испытаний"

Бизнес-процесс предназначен для оформления акта проведения приемочных испытаний с целью подтверждения готовности системы к эксплуатации.

Процесс применяется в рамках приложения "Комплект документов по ИБ".

## Запуск процесса

Процесс запускается автоматически в рамках БП "Оформление документов по ИБ"

## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Сценарий "Подготовка данных"

В рамках выполнения скрипта система подготавливает и записывает в контекст процесса все необходимые данные для дальнейшей работы.

После выполнения скрипта процесс переходит к шагу 2.

<a id="step-2"></a>
## Шаг 2 Задача: "Оформление на оформление акта ПИ"

Название задачи "Оформление акта ПИ".

В рамках задачи АИБ должен заполнить данные об АРМах и СЗИ

После выполнения задачи процесс переходит к шагу 3.

<a id="step-3"></a>
## Шаг 3 Сценарий: "Изменить статус акта"

В рамках выполнения скрипта система должна изменить статус акта на "Корректировка"

После выполнения скрипта процесс переходит к шагу 2.

<a id="step-4"></a>
## Шаг 4 Сценарий: "Генерация файла по шаблону"

В рамках выполнения скрипта система должна сформировать печатную форму акта по шаблону:

АКТ проведения ПИ ПС.docx

АКТ проведения ПИ ПС.docx (с переменными)

После выполнения скрипта процесс переходит к шагу 5.

<a id="step-5"></a>
## Шаг 5 Сценарий: "Изменить статус акта"

В рамках выполнения скрипта система должна изменить статус акта на "Подписание"

После выполнения скрипта процесс переходит к шагу 6.

<a id="step-6"></a>

<a id="step-7"></a>
## Шаг 7 Сценарий: "Изменить статус акта"
