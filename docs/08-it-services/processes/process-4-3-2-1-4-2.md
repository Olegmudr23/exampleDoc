# Бизнес-процесс "Подключение IT-услуги без юр. оформления"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.3.2.1.4.2**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

*Рисунок 19 — Схема бизнес процесса "Подключение IT-услуги без соглашения" — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Бизнес-процесс предназначен для запуска процесса по подключению выбранной IT-услуги, в ходе которой не требуется подписание соглашения.

## Зоны ответственности

Описание зон ответственности БП "Подключение IT-услуги"

| Зона ответственности | Тип | Описание |
| --- | --- | --- |
| Инициатор | Динамическая | Пользователь портала по подключению IT-услуг. |
| Поставщик IT-услуг | Динамическая | Пользователи, которые относятся к поставщику IT-услуг. |
| Сотрудники организации | Динамическая | Сотрудники подключаемой организации. |


## Входные параметры

| Входной параметр | Описание |
| --- | --- |
| Услуга | Услуга, которую выбрал инициатор процесса на портале по подключению IT-услуг. |
| Инициатор | Внешний пользователь, который работает на портале по подключению IT-услуг. |


## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Задача "Заполнить заявку на подключение"

Пользователи инициатор получает задачу на заполнения заявки на подключение.

| Параметр | Описание |
| --- | --- |
| Название по шаблону | Заполнить заявку на подключение услуги |
| Оповещение | Оповещать исполнителя о постановке задачи |
| Переназначение | Нет. |
| Выполнять от имени | Система. |
| Правила исполнения | - |
| Форма задачи | Описание |
| Текст | $(Инициатор. Пользователь IT-услуги. Организация) в лице $(Инициатор. Пользователь IT-услуги) (Родительский падеж) просит подключить $(Услуга. Наименование) |
| Организация | Элемент приложения "Организации".<br>Для выбора доступен один элемент приложения. При ее смене обновлять "Текст" на форме задачи. |
| Выбор подписки | Категория:<br>Для всей организации;<br>Для структурной единицы;<br>Для конкретных пользователей. |
| Объект доступности | Элемент приложения.<br>Если "Выбор подписки" = "Для всей организации", то заполняется автоматически организацией инициатора (недоступно для редактирования).<br>Если "Выбор подписки" = "Для структурной единицы", то доступны для выбора все [Структурная единица. Организация] = [Инициатор. Организация].<br>Если "Выбор подписки" = "Для конкретных пользователей", то доступны для выбора все [Пользователь IT-услуг. Организация] = [Инициатор. Организация]. |
| АИБ | Список АИБов.<br>Заполнять автоматически из [Инициатор. Организация. Администраторы информационной безопасности]. (Недоступно для редактирования) |
| Ответственный IT | Список ответственных IT.<br>Заполнять автоматически из [Инициатор. Организация. Ответственные IT]. (Недоступно для редактирования) |
| Переходы | Отправить заявку (Переход на шаг 2).<br>Отменить (Завершение процесса). |


<a id="step-2"></a>
## Шаг 2 Создание элемента приложения "Создать заявку на подключение"

Система автоматически создает запись в приложении "Заявки на подключение". Переход на шаг 3.

| Текст заявки | Из шага 1. |
| --- | --- |
| Организация | Из шага 1. |
| Подписка | Из шага 1. |
| Объект доступности | Из шага 1. |
| АИБ | Из шага 1. |
| Ответственный IT | Из шага 1. |
| Тип заявки | На подключение. |
| Услуга | Из БП "Подключение IT-услуг. |


<a id="step-3"></a>
## Шаг 3 Сценарий "Получить всех пользователей из поставщика IT-услуги"

Система автоматически ищет из [Услуга. Поставщик] соответствующую запись в группах и дает право на просмотр всем данным пользователям. Переход на шаг 4.

<a id="step-4"></a>
## Шаг 4 Задача "Подтвердить подключение"

Пользователи поставщика IT услуги получает задачу на подтверждение заявки на подключение.

| Параметр | Описание |
| --- | --- |
| Название по шаблону | Заполнить заявку на подключение услуги |
| Оповещение | Оповещать исполнителя о постановке задачи |
| Переназначение | Да |
| Выполнять от имени | Система. |
| Правила исполнения | Кто первый? |
| Форма задачи | Описание |
| Заявка на подключение | Форма просмотра созданной ранее заявки на подключение. |
| Переходы | Подключить (Переход на шаг 5).<br>Отказать (предусмотреть обязательное заполнение причины отказа) (Переход на шаг 10). |


<a id="step-5"></a>
## Шаг 5 Смена статуса "Заявка на подключение - > Исполнена"

Система автоматически изменяет статус заявки на подключение на значение "Исполнена". Переход на шаг 6.

<a id="step-6"></a>
## Шаг 6 Создание элемента приложения "Создать заявку на подключение"

Система автоматически создает запись в приложении "Доступность услуг". Переход на шаг 7.

<a id="step-7"></a>
## Шаг 7 Сценарий "Включить отображение услуги на портале самообслуживания"

Система автоматически для всех внешних пользователей, которым доступна текущая услуга отображает ее на портале самообслуживания. Переход на шаг 8.

<a id="step-8"></a>
## Шаг 8 Сценарий "Получить всех потребителей подписки"

Система автоматически получает всех пользователей, которым теперь доступна и услуга и записывает их в контекстную переменную процесса. Переход на шаг 9.

<a id="step-9"></a>
## Шаг 9 Оповещение на email "Успешное подключение"

Cистема автоматически отправляет email полученным пользователям:

| Тема сообщения | Оферта на подключение IT-услуг не согласована |
| --- | --- |
| Текст сообщения | Добрый день!<br><br>Теперь вы можете формировать заявки по услуге $(Услуга. Название) на портале самообслуживания. |
| Обработка ошибок | Завершение процесса. |


<a id="step-10"></a>
## Шаг 10 Смена статуса "Заявка на подключение - > Отказ"

Система автоматически изменяет статус заявки на подключение на значение "Отказ". Переход на шаг 11.

<a id="step-11"></a>
## Шаг 11 Оповещение на email "Отказ в подключении"

Cистема автоматически отправляет email полученным пользователям:

| Тема сообщения | Оферта на подключение IT-услуг не согласована |
| --- | --- |
| Текст сообщения | Добрый день!<br><br>Ваша заявка на подключение услуги:  $(Услуга. Название) - отклонена.<br>Причина: $(Заполнятся из шага 4.) |
| Обработка ошибок | Завершение процесса. |
