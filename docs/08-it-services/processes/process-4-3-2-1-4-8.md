Бизнес-процесс предназначен для формирования документа расторжение. Процесс запускается из БП "Отключение услуги".

## Зоны ответственности

Описание зон ответственности БП "Формирование юридического документа на расторжение".

| Зона ответственности | Тип | Описание |
| --- | --- | --- |
| Инициатор | Динамическая | Пользователь, имеющий доступ на просмотр элемента приложения. |
| Сотрудники организации | Динамическая | Пользователи, которые относятся к организации. |


## Входные параметры

| Входной параметр | Описание |
| --- | --- |
| Юридический документ | Действующий документ. |
| Услуга | Услуга, которую планируется отключить. |


## Форма запуска

| Параметр | Описание |
| --- | --- |
| "Вы уверены, что хотите отключить услугу?" | Текст. Недоступно для редактирования. |
| Переходы | Да (Переход на шаг 1);<br>Нет (Завершение процесса). |


## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Сценарий "Сгенерировать текст юридического документа"

Система автоматически записывает значение из [Услуга. Шаблон расторжения соглашения/оферты на подключение IT-услуги] в контекстную переменные процесса. Далее переход на шаг 2.

<a id="step-2"></a>
## Шаг 2 Задача "Заполнить юридический документ"

Пользователь инициатор получает задачу на заполнение юридического документа:

| Параметр | Описание |
| --- | --- |
| Название по шаблону | Заполнить информацию для отключения IT услуги |
| Оповещение | Оповещать исполнителя о постановке задачи |
| Переназначение | Да |
| Выполнять от имени | Система. |
| Правила исполнения | - |
| Форма задачи | Описание |
| Текст юридического документа | Из шага 1 текст должен сгенерироваться по шаблону.<br>Доступно для редактирования текста. |
| Организация | Из входного параметра. |
| Тип документа | "Расторжение"<br>Недоступно для редактирования. |
| АИБ | Список АИБов.<br>Заполнять автоматически из [Инициатор. Организация. Администраторы информационной безопасности]. (Недоступно для редактирования) |
| Ответственный IT | Список ответственных IT.<br>Заполнять автоматически из [Инициатор. Организация. Ответственные IT]. (Недоступно для редактирования) |
| IT-услуга | Из входного параметра.<br>Недоступно для редактирования |
| Подписка | Для выбора доступно одно из значений:<br>Для всей организации;<br>Для структурной единицы;<br>Для конкретных пользователей.<br>Из входного параметра.<br>Недоступно для редактирования. |
| Объект доступности | Элемент приложения "Пользователи IT-услуг" или "Структурные единицы" или "Организации". Предусмотреть выбор только в рамках одного из справочника CRM.<br>Из входного параметра.<br>Недоступно для редактирования. |
| Категория документа | Из входного параметра. |
| Переходы | Готово (Переход на шаг 3) (Доступно после заполнения всех полей).<br>Отменить (Завершение процесса). |

<a id="step-3"></a>
## Шаг 3 Создание элемента приложения "Создать юридический документ"

Система автоматически создает запись в приложении "Юридические документы".

| Параметр | Описание |
| --- | --- |
| Юридический документ | Из шага 2. |
| Организация | Из шага 2. |
| IT-услуга | Из шага 2. |
| Подписка | Из шага 2. |
| Объект доступности | Из шага 2. |
| Тип документа | Расторжение. |
| Категория документа | Тип подключения из шага 2. |


<a id="step-4"></a>
## Шаг 4 Сценарий "Раздать права на просмотр"

Система автоматически ищет из [Услуга. Поставщик] соответствующую запись в группах и дает право на просмотр всем данным пользователям. Завершение процесса.
