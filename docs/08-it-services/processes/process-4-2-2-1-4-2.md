| --- | --- | --- |
| Инициатор | Динамическая | Ответственные за соглашения в CRM. |


## Входные параметры

Инициатор — Пользователь с правами доступа на работу с офертами.

| Входной параметр | Описание |
| --- | --- |
| Кому отправить ссылку на подключение?* | Из БП "Создание оферты"<br>Внешний пользователь, который получает оферту. |


## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Сценарий "Проверить наличие действующей оферты"

Система автоматически осуществляет поиск оферты, по следующему принципу:

Найти по [Внешний пользователь. email] = [Пользователь IT-услуг. email] запись получателя IT-услуг.

Найти [Пользователь IT-услуг. Организация] = [Оферта для CRM. Организация] и [Оферта CRM. Статус] = "Действующая" и [Оферта CRM. Тип оферты] = "Для Получателя IT-услуг".

Успешный/неуспешный поиск записать в контекстную переменную процесса.

Записать найденного Пользователя IT-услуг в контекстную переменную процесса.

Переход на шаг 2.

<a id="step-2"></a>
## Шаг 2 Шлюз "У пользователя есть действующая оферта?"

| Переход | Описание |
| --- | --- |

| Обработка ошибок | Переход на шаг 5. |


<a id="step-5"></a>
## Шаг 5 Задача "Заполнить оферту"

Система автоматически формирует задачу на оферту по шаблону (Оферта получателя IT-услуг) (рисунок 6):

*Рисунок 6 - Макет оферты для получателя. — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Описание блоков:

"Текст оферты" - текст, который не изменяется.

"Генерируемый текст оферты" - генерируемый текст с переменными $(Пользователь IT- Услуг. ФИО) и $(Пользователь IT- Услуг. Организация. Название)

"Ответственные за взаимодействие" - выбор внешних пользователей (доступен выбор до 5 единиц).

"Организация" - выбор элемента приложения "Организация" (По умолчанию текущая организация пользователя, недоступно для редактирования).

"Организация подписанта" -  выбор элемента приложения "Организация" (По умолчанию текущая организация пользователя, доступно для редактирования).

"Подписант" - выбор элемента приложения "Пользователи IT-услуг" (для выбора доступен 1 значение) (Для выбора доступны связанные с организацией подписанта значения).

"С содержанием ознакомился, все верно" - чек-бокс.

"Ссылка 1" и "Ссылка 2" - ссылки на внешние ресурсы.

"Область для загрузки файлов" - область для вложений.

"Сохранить" - кнопка доступна и активна, если "С содержанием ознакомился, все верно" = "Да". Далее переход на шаг 6.

Сменить организацию" - кнопка запускает БП "Сменить организацию".

Завершение процесса.
