# БП "Оформление документов по ИБ"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.5.2.19**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

*Рисунок 111 — Схема бизнес процесса "Оформление документами по ИБ" — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Бизнес-процесс предназначен для оформления документов по информационной безопасности с целью обеспечения соответствия установленным требованиям и защиты информации.

Процесс применяется в рамках приложения "Комплект документов по ИБ".

## Зоны ответственности

Описание зон ответственности БП  "Оформление документами по ИБ"

| Зона ответственности | Тип | Описание |
| --- | --- | --- |
| АИБ получателя | Динамическая | Группа пользователей из приложения "Организации" |
| АИБ поставщика | Динамическая | Определяется по записи ИС |


## Запуск процесса

Процесс запускается автоматически в рамках БП "Подключение к IT-услуге"

## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Сценарий "Подготовка данных"

В рамках выполнения скрипта система подготавливает и записывает в контекст процесса все необходимые данные для дальнейшей работы.

После выполнения скрипта процесс переходит к шагу 2.

<a id="step-2"></a>
## Шаг 2 Скрипт:  "Создать запись приложения"

Скрипт создает запись приложения "Комплект документов по ИБ"

После выполнения задачи процесс переходит к шагу 3

<a id="step-3"></a>
## Шаг 3 Ознакомление: "Ознакомление с документами по ИБ"

Блок : Ознакомление

Название задачи "Ознакомление с документами по ИБ".

В рамках задачи АИБ должен подтвердить ознакомление с требованиями на эксплуатацию ГИС.

Описание параметров на форме задачи «Ознакомление с документами по ИБ».

| № п/п | Параметр | Тип | Обязательность | Видимость | Комментарий |
| --- | --- | --- | --- | --- | --- |
| 1 | Файл акта | Файл | Только для чтения | Да | Виджет предпросмотр файла<br>Файл нужно получить из соответствующей записи приложения "Информационные системы" |
| 2 | Информационная панель | Текст | Только для чтения | Да | Нажимая кнопку “Ознакомлен”, вы подтверждаете получение информации. После подтверждения вам будут назначены задачи по оформлению документов по информационной безопасности. |


*Рисунок 112 — Форма задачи "Ознакомление с документами по ИБ" — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

В работе - кнопка закрепляет задачу за одним исполнителем из группы, скрывая её у остальных.

Ознакомлен - система сохраняет подписанную версию документа, процесс переходит к шагу 4

<a id="step-4"></a>
## Шаг 4 Сценарий: "Изменить статус "Оформление документов"

В рамках выполнения скрипта система должна изменить статус записи приложения "Комплект документов по ИБ" на "Оформление документов"

После выполнения скрипта процесс переходит к шагу 5.

## Шаг 9 Согласование: "Проверить документы по ИБ получателя"

Блок: Согласование

Название задачи: Проверка документов по ИБ получателя

В рамках задачи АИБ должен проверить документы по информационной безопасности получателя. После проверки АИБ может либо подтвердить соответствие документов требованиям ИБ, либо отправить документы на доработку.

| № п/п | Параметр | Тип | Обязательность | Видимость | Комментарий |
| --- | --- | --- | --- | --- | --- |
| 1 | Акт установки и настройки СЗИ | Файл | Только для чтения | Да | Виджет предпросмотр файла |
| 2 | Техпаспорт | Файл | Только для чтения | Да | Виджет предпросмотр файла |
| 3 | Акт проведения ПИ | Файл | Только для чтения | Да | Виджет предпросмотр файла |


| № п/п | Параметр | Тип | Обязательность | Видимость | Комментарий |
| --- | --- | --- | --- | --- | --- |
| 1 | Какой документ изменить | Категория | Да | Да | - Техпаспорт<br>- Акт СЗИ<br>- Техпаспорт и акт СЗИ |
| 2 | Комментарий по отказу | Текст | Да | Да |  |
