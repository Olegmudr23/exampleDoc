*Рисунок 24 — Схема бизнес процесса "Приостановка предоставления услуги" — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Бизнес-процесс предназначен для запуска процесса приостановки предоставления услуги и формирования задачи для ответственных за взаимодействие. Процесс запускается по кнопке "Приостановить обслуживание" на форме просмотра Юридического документа в статусе "Действует" или на форме просмотра "Заявки на подключение" в статусе "Исполнена".

## Зоны ответственности

Описание зон ответственности БП "Приостановка предоставления услуги"

| Зона ответственности | Тип | Описание |
| --- | --- | --- |
| Инициатор | Динамическая | Внутренний пользователь, который имеет доступ к приложению "Юридические документы". |
| Ответственные  <br>за взаимодействие <br>в CRM | Динамическая | Ответственные за взаимодействие |


## Входные параметры

| Входной параметр | Описание |
| --- | --- |
| Инициатор | Внешний пользователь, который работает на портале по подключению IT-услуг. |
| Заявка на подключение или Юридический документ | Элемент приложения сформированный при подключении услуги. |


## Запуск процесса

| Параметры | Описание |
| --- | --- |
| Описание* | Текст |
| Срок исполнения* | Дата/Время (только Дата) |
| Переходы | Готово (Переход на шаг 1);<br>Отмена (Завершение процесса). |


## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Сценарий "Получить ответственных за взаимодействие"

Система автоматически осуществляет поиск [Оферта. Организация] = [Заявка на подключение. Организация] или [Юридический документ. Организация]. В найденной оферте записывает "Ответственные за взаимодействие" в контекстную переменную процесса. Далее переход на шаг 2.

<a id="step-2"></a>
## Шаг 2 Задача "Выполнить задачу"

Пользователи, полученные на шаге 1 получает задачу на выполнение поручения.

| Параметр | Описание |
| --- | --- |
| Название по шаблону | Выполнить задачу |
| Оповещение | Оповещать исполнителя о постановке задачи |
| Переназначение | Нет. |
| Выполнять от имени | Система. |
| Правила исполнения | Кто первый? |
| Время исполнения | Срок исполнения (из формы запуска) |
| Прервать | По истечению срока. |
| Форма задачи | Описание |
| Текст | Описание (из формы запуска) |
| Переходы | Готово (Завершение процесса). |
