## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Сценарий: "Выбрать записи приложений"

В рамках выполнения скрипта система должна:

Собрать определённые записи из приложения «Комплект документов по ИБ», которые удовлетворяют следующим условиям:

Статус записи не равен значению «Документы оформлены».

Дата создания записи более 30 дней назад относительно текущей даты.

В атрибуте "Превышен срок оформления документов" установлено значение "Нет"

<a id="step-2"></a>
## Шаг 2 Шлюз: "Список пуст?"

Описания переходов в шлюзе.

| Переход | Условия |
| --- | --- |
| 2.1 Да | Система проверяет наличие записей в списке, если их нет, то процесс идет по данному переходу к выходу. |
| 2.2 Нет | Если условие 2.1 не выполнено, то процесс переходит к шагу  3 |


<a id="step-3"></a>
## Шаг 3 Сценарий: "Выбрать одну запись"

Сценарий выбирает запись из списка из списка .

После выполнения скрипта процесс переходит к шагу 4

<a id="step-4"></a>
## Шаг 4 Сценарий: "Отметить просроченную запись"

В рамках выполнения скрипта система должна отметить записи, у которых превышен срок оформления документов, присвоив значение "Да" в атрибуте "Превышен срок оформления документов"

После выполнения скрипта процесс переходит к шагу 5

<a id="step-5"></a>

Описания переходов в шлюзе.

| 5.2 Да | Если условие 5.1 не выполнено, то процесс переходит к выходу. |
