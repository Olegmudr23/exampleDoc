Бизнес-процесс предназначен для запуска процесса по подключению выбранной IT-услуги, в ходе которой требуется подписание документов.

## Зоны ответственности

Описание зон ответственности БП "Подключение IT-услуги требующей юридического оформления".

| Зона ответственности | Тип | Описание |
| --- | --- | --- |
| Инициатор | Динамическая | Пользователь портала по подключению IT-услуг. |
| Поставщик IT-услуг | Динамическая | Пользователи, которые относятся к поставщику IT-услуг. |
| Сотрудники организации | Динамическая | Сотрудники подключаемой организации. |


## Входные параметры

| Входной параметр | Описание |
| --- | --- |
| Услуга | Услуга, которую выбрал инициатор процесса на портале по подключению IT-услуг. |
| Инициатор | Внешний пользователь, который работает на портале по подключению IT-услуг. |


## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Сценарий "Сгенерировать текст оферты"

Система автоматически записывает значение из [Услуга. Шаблон соглашения/оферты на подключение IT-услуги], [Услуга. Тип подключения] в контекстные переменные процесса. Далее переход на шаг 2.

<a id="step-2"></a>
## Шаг 2 Задача "Заполнить юридический документ"

Пользователь инициатор получает задачу на заполнение юридического документа:

| Параметр | Описание |
| --- | --- |
| Название по шаблону | Заполнить информацию для подключения IT услуги |
| Оповещение | Оповещать исполнителя о постановке задачи |
| Переназначение | Да |
| Выполнять от имени | Система. |
| Правила исполнения | - |
| Форма задачи | Описание |
| Текст юридического документа | Из шага 1 текст должен сгенерироваться по шаблону.<br>Доступно для редактирования текста. |
| Тип подключения | Из шага 1 записанная контекстная переменная.<br>Недоступно для редактирования. |
| Подписант* | Элемент приложения "Внешние пользователи".<br>Для выбора доступен один пользователь. |
| АИБ | Список АИБов.<br>Заполнять автоматически из [Инициатор. Организация. Администраторы информационной безопасности]. (Недоступно для редактирования) |
| Ответственный IT | Список ответственных IT.<br>Заполнять автоматически из [Инициатор. Организация. Ответственные IT]. (Недоступно для редактирования) |
| Вложения | Файлы. |
| IT-услуга | Из БП "Подключение к IT-услуге". |
| Подписка* | Для выбора доступно одно из значений:<br>Для всей организации;<br>Для структурной единицы;<br>Для конкретных пользователей. |
| Объект доступности* | Элемент приложения "Пользователи IT-услуг" или "Структурные единицы" или "Организации". Предусмотреть выбор только в рамках одного из справочника CRM. |
| Переходы | Готово (Переход на шаг 3) (Доступно после заполнения всех полей).<br>Отменить (Завершение процесса). |


*Рисунок 22 - Макет задачи. — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

<a id="step-3"></a>
## Шаг 3 Создание элемента приложения "Создать юридический документ"

Система автоматически создает запись в приложении "Юридические документы". Переход на шаг 4.

| Юридический документ | Из шага 2. |
| --- | --- |
| Организация | [Инициатор. Пользователь IT-услуги. Организация] |
| Подписант | Из шага 2. |
| Вложения | Из шага 2. |
| IT-услуга | Из шага 2. |
| Тип заявки | На подключение. |
| Подписка | Из шага 2. |
| Объект доступности | Из шага 2. |
| Тип документа | Первичное. |
| Категория документа | Тип подключения из шага 2. |


<a id="step-4"></a>
## Шаг 4 Сценарий "Раздать права на просмотр"

Система автоматически ищет из [Услуга. Поставщик] соответствующую запись в группах и дает право на просмотр всем данным пользователям. Завершение процесса.
