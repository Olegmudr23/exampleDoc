# БП "Формирование оферты для Внешнего поставщика IT-услуг"

[Каталог ТЗ](../README.md) · [Все примеры](../../../README.md)

Исходный раздел: **4.2.2.1.4.4**. Обезличенное описание из технического задания. Текстовые шаги, условия, параметры форм и таблицы перенесены без сокращения. Нумерация и проектные формулировки сохранены.

*Рисунок 9 — Схема бизнес процесса "Формирование оферты для Внешнего поставщика IT-услуг" — ссылка на рисунок исходного ТЗ; изображение в текстовую страницу не включено.*

Бизнес-процесс предназначен для формирования оферты для Внешнего поставщика IT-услуг. Запуск процесса осуществляется по кнопке "Пригласить внешнего поставщика" на форме просмотра оферты, которая в статусе "Действует" и "Тип оферты" = "Для Внутреннего поставщика IT-услуг" .

Зоны ответственности.

Описание зон ответственности БП "Формирование оферты для Внешнего поставщика IT-услуг"

| Зона ответственности | Тип | Описание |
| --- | --- | --- |
| Инициатор | Динамическая | Ответственные за соглашения в CRM или пользователь, который имеет право на просмотр оферты. |
| ЦКИТ | Статическая | Центр качества. |
| Подписант | Динамическая | Подписант со стороны внешнего поставщика. |
| Сотрудники | Динамическая | Сотрудники внешнего поставщика. |


## Форма запуска

| Параметр | Описание |
| --- | --- |
| Основание | Текст.<br><br>Доступно для редактирования |
| Название организации | Текст.<br>Доступно для редактирования |
| Вложения | Файлы.<br>Для загрузки доступно несколько вложений. |
| Реквизиты | Файлы.<br>Для загрузки доступно несколько вложений. |
| Услуга | Элемент приложения "Услуги", у которой [Уровень услуги] = "1 уровень". |
| Руководитель организации | Таблица (для заполнения только 1 строка): |
| Сотрудники | Таблица (для заполнения несколько строк): |
| Переходы | Отправить (Переход на шаг 1);<br>Отмена (Завершение процесса). |


## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Задача "Подтвердить заявку на приглашение Внешнего поставщика"

Пользователи из ЦКИТ получают задачу на подтверждение заявки на приглашение Внешнего поставщика.

| Параметр | Описание |
| --- | --- |
| Название по шаблону | Подтвердить заявку на приглашение Внешнего поставщика |
| Оповещение | Оповещать исполнителя о постановке задачи |
| Переназначение | Разрешить |
| Выполнять от имени | Система. |
| Правила исполнения | Кто первый? |
| Форма задачи | Описание |
| Текст | Зарегистрируйте необходимые объекты в системе.<br><br>Недоступно для редактирования. |
| Основание | Из формы запуска.<br>Недоступно для редактирования. |
| Название организации | Из формы запуска.<br>Недоступно для редактирования. |
| Вложения | Из формы запуска.<br>Недоступно для редактирования. |
| Реквизиты | Из формы запуска.<br>Недоступно для редактирования. |
| Услуга | Из формы запуска.<br>Недоступно для редактирования. |
| Руководитель организации | Из формы запуска.<br>Недоступно для редактирования. |
| Сотрудники | Из формы запуска.<br>Недоступно для редактирования. |
| Зарегистрированная организация* | Элемент приложения "Организации".<br>Для выбора доступно одно из значений. |
| Организация подписанта* | Заполнено значением из "Зарегистрированная организация" (доступно для редактирования).<br>Элемент приложения "Организации".<br>Для выбора доступно одно из значений. |
| Подписант* | Элемент приложения "Пользователи IT-услуг".<br>Для выбора доступно одно из значений, связанной с организацией. |
| Переходы | Готово (Переход на шаг 2);<br>Отмена (Завершение процесса). |


Предусмотреть запись всех данных в контекстные переменные процесса.

<a id="step-2"></a>
## Шаг 2 Создание элемента "Создать черновик оферты"

Система автоматически создает оферту:

| Параметр | Описание |
| --- | --- |
| Оферта | Шаблон оферты для Внешнего поставщика IT-услуг. |
| Организация | Зарегистрированная организация из шага 1. |
| Тип оферты | Для Внешнего поставщика IT-услуг. |
| Подписант | из шага 1. |
| Пригласивший внутренний сотрудник | Инициатор процесса. |
| Вложения | Из шага 1. |


Завершение процесса.

<a id="step-3"></a>
## Шаг 3 Задача "Подписать оферту для Внешнего поставщика IT-услуг"

Cистема автоматически назначает подписанту задачу для подписи оферты (используется УКЭП) для Внешнего поставщика IT-услуг.

| Переназначение | Нет |
| --- | --- |
| Приложение | Оферта для CRM. |
| Выход при успешном подписании | Шаг 4. |
| Выход при неуспешном подписании | Завершение процесса. |
| Провайдер по умолчанию | КриптоПро |


Для подписания 14 дней, в ином случае завершение процесса. Переход на шаг 4.

<a id="step-4"></a>
## Шаг 4 Смена статуса "Оферта → Действует"

Cистема автоматически изменяет статус оферты. Переход на шаг 5.

<a id="step-5"></a>
## Шаг 5 Сценарий "Получить всех пользователей подключенной организации"

Система автоматически получает всех пользователей, которые связаны с текущей организацией и записывает в контекстную переменную процесса. Далее переход на шаг 6.

<a id="step-6"></a>
## Шаг 6 Задача "Ознакомиться с онбордингом"

Пользователи, найденные на шаге 3 получают задачу:

| Название | Ознакомиться с онбордингом |
| --- | --- |
| Оповещение | Оповещать исполнителя о постановке задачи |
| Переназначение | Нет. |
| Выполнять от имени | Система. |
| Правила исполнения | Параллельно. |
| Форма задачи | Описание |
| Онбординг | Многострочный текст. |
| Переходы | Готово (Завершение процесса). |
