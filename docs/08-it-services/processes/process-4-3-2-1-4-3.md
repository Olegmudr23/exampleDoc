Бизнес-процесс предназначен для запуска процесса по согласованию и ознакомлению соглашения внутри организации инициатора (функционал аналогичен коробочной кнопке "Отправить на согласование/ознакомление"). Кнопка доступна для приложений "Оферты для CRM", "Заявки на подключение", "Юридические документы".

## Зоны ответственности

Описание зон ответственности БП "Внутреннее согласование/ознакомление соглашения"

| Зона ответственности | Тип | Описание |
| --- | --- | --- |
| Инициатор | Динамическая | Пользователь имеющий доступ на просмотр соглашения. |


## Форма запуска

| Входной параметр | Описание |
| --- | --- |
| На ознакомление / На согласование | Доступен выбор одного из значений:<br>На ознакомление.<br>На согласование. |
| Согласующие* | Доступно, если было выбрано "На согласование".<br><br>Для выбора доступны внешние пользователи. |
| Согласовать до* | Дата/время |
| Тип согласования | Выбор из "Параллельное/Последовательное".<br>Доступно, если в [Согласующие] выбрано несколько пользователей. |
| Прерывать при первом отказе | Выбор из "Прервать/Продолжить".<br>Доступно, если в [Согласующие] выбрано несколько пользователей. |
| Получатели* | Доступно, если было выбрано "На ознакомление".<br>Для выбора доступны внешние пользователи. |
| Назначить задачу и сформировать лист ознакомления | Доступно, если было выбрано "На ознакомление".<br>Выбор "Да/Нет".<br>По умолчанию "Да". |
| Ознакомиться до | Дата/время |
| Комментарий | Текст.<br>Доступно, если было выбрано "На ознакомление". |
| Переходы | Отправить (Переход на шаг 1).<br>Отмена (Завершение процесса). |


Кнопка доступна только внешним пользователям и если "Статус" в соглашении "Новая".
