Бизнес-процесс предназначен для внесения изменений в технический паспорт путём актуализации документации по информационной безопасности.

Процесс применяется в рамках приложения "Комплект документов по ИБ".

## Запуск процесса

Процесс запускается по кнопке "Актуализировать" с формы просмотра записи приложения "Техпаспорты"

Инициатор — Пользователь с правами доступа на актуализацию техпаспорта организации.

Форма запуска:

| № п/п | Параметр | Комментарий |
| --- | --- | --- |
| 1 | Информационная панель | При добавлении АРМ в справочник вы обязаны обеспечить актуализацию соответствующих технических паспортов вашей организации. |


## Шаги процесса

<a id="step-1"></a>
## Шаг 1 Сценарий "Подготовка данных"

В рамках выполнения скрипта система должна выбрать данные из записи приложения "Техпаспорты", с которой был запущен процесс, для последующей передачи их в подпроцесс.

<a id="step-2"></a>
## Шаг 2 Подпроцесс: "Генерация техпаспорта"

Входные переменные.

| Процесс | Родительский |
| --- | --- |
| Состав пользовательских ПТC | Состав пользовательских ПТC |
| Сеть и телекоммуникационное оборудование | Сеть и телекоммуникационное оборудование |
| Инициатор | АИБ поставщика |


После завершения подпроцесса текущий процесс идет к выходу.
