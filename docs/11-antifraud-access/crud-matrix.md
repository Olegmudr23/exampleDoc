# Полная CRUD модель антифрода и верификации

[Описание модели](README.md) · [Все региональные группы в CSV](crud-matrix.csv)

Матрица восстановлена из полного текстового документа, предоставленного после PDF. Покрыты все 15 объектов. Повторяющиеся региональные группы объединены только в представлении Markdown; CSV сохраняет все 21 группу.

## Обозначения

- `C` — создание, `R` — чтение, `U` — изменение, `D` — удаление.
- `-` — право не предоставлено.
- Звёздочка сохранена из источника и означает условное право. Все условия, в том числе указанные текстом без звёздочки, приведены ниже.

## Условия применения прав

| Объект или правило | Условие |
| --- | --- |
| Членство в группе | Пользователь добавляется в группу напрямую. Вложенные группы и элементы оргструктуры не учитываются. |
| Проверки | Операционные роли видят проверки своей страны. Для сотрудников, старших сотрудников и руководителей антифрода создание проверки допускается только через бизнес-процесс. |
| Заявки на верификацию | Операционные роли работают с заявками своей страны. Сотрудник верификации изменяет только заявку, в которой назначен в поле «Верификатор». |
| Состояния регистрации CRM | Роли верификации изменяют состояние только в рамках бизнес-процесса. |
| Контрагенты | Роли верификации изменяют контрагента только в рамках бизнес-процесса. |
| Активность | Для всех операционных ролей изменение допускается, если пользователь является автором или исполнителем задачи. |
| Очереди антифрода | Руководитель и старший сотрудник работают только с очередями проверок. У рядового сотрудника права на объект «Очереди» отсутствуют. |
| Очереди верификации | Руководитель работает только с очередями заявок на верификацию. У сотрудника права на объект «Очереди» отсутствуют. |
| Администратор | Полный CRUD без ограничений по стране. |

Географические ограничения в исходнике явно заданы для проверок и заявок; они не распространены здесь предположением на все справочники. В колонке «Примечания» у операционных ролей указано `-`, отдельные примечания для администратора не заполнены. Содержательные ограничения из ячеек матрицы перенесены в таблицу выше и в колонку «Условия» CSV.

## Полнота переноса

Из исходника перенесены 20 региональных групп пяти операционных ролей и одна системная группа администратора. Права для каждого объекта сверены между четырьмя региональными вариантами каждой роли. Колонки справа, отсутствовавшие в PDF, включены по полному текстовому источнику.
