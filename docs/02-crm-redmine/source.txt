2. Требования, цели, задачи и ограничения
2.1. Требования к разработке модуля интеграции
Реализация интеграционного взаимодействия между CRM и Redmaine посредством API
Допускаются только асинхронные GET, PUT и POST запросы
Запросы должны обеспечить функциональность работы с задачами в Redmaine
2.2. Цель разработки модуля интеграции
Создание интеграционного взаимодействия с системой Redmaine
2.3. Задачи разработки модуля
Настроить интеграционный обмен между CRM и телефонией РТУ
3. Описание интеграционных задач/сценариев и используемых методов:
3.1.1. Авторизация системы CRM в Redmaine: 


Авторизация CRM в Redmaine происходит по токену. В настройках модуля нужно создать поле ввода API endpoint и поле ввода токен. Токен нужно получить в Redmaine https://www.redmine.org/projects/redmine/wiki/rest_api. У учетной записи должны быть привилегии на объекты, с которыми планируется интеграция, так как токен непосредственно привязан к учетной записи.

3.1.2 Настройки модуля

Необходимо создать таблицу типов и форматов файлов.

Таблица имеет следующую структура

Название столбца

Тип данных

Примечание

MIME-type
